# GIPUZKOA 360

Un coordinador con ocho herramientas deterministas, incluida la introspección de capacidades. `main.py` expone `build_agent(model)` y desactiva
Internet. Los cálculos, validaciones y contratos viven en módulos pequeños y utilizan solo la biblioteca
estándar de Python; el modelo interpreta las preguntas y explica las salidas.

Los archivos `TEST_*` de `tests/fixtures/` son exclusivamente sintéticos. No deben incluirse en una versión
presentada como análisis real de Gipuzkoa.
