# Checklist de publicación humana

Esta lista no autoriza ni ejecuta una entrega.

- [ ] Integrar las ramas finales revisadas según el [plan](internal/release/INTEGRATION_PLAN.md).
- [ ] Cerrar todos los Critical/High del [registro de incidencias](internal/release/AUDIT.md).
- [ ] Repetir el verificador completo sobre el SHA final.
- [ ] Confirmar que los 12 archivos congelados no cambiaron; si cambiaron, repetir validación privada del portal.
- [ ] Verificar main después del merge y solo entonces cambiar la rama por defecto.
- [ ] Abrir el repositorio sin sesión y recorrer los cinco documentos canónicos.
- [ ] Contrastar en el portal vigente fechas, restricciones, identidad de equipo y permisos.
- [ ] Revisar el [pack mínimo](internal/release/SUBMISSION_PACK.md); adjuntar solo material aprobado.
- [ ] Una persona autorizada decide si publica Entrega.

La versión privada existente permanece intacta. No prometer tiempos de respuesta del portal a partir de milisegundos del motor local.
