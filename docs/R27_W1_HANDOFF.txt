Observed defect and diagnosis
The captured R26 public JSON classified Legazpi as false -> true, while the
model's final prose said it remained outside both thresholds. This establishes
a tool-to-answer contradiction, not an arithmetic defect. The core acceso()
uses unrounded Euclidean EPSG:25830 distance <= threshold_km*1000. escenario()
retains those booleans and displays distance rounded to one decimal. The public
claims/classifications preview selected ten rows. No authoritative complete
transition ledger was present. No internal model cause is claimed.

Bounded implementation
The build appends scripts/vnext_agent/r27_threshold.py to the exact frozen R26
tools.py. It copies main.py and every other ZIP member byte-for-byte. Original
R26 files and package remain untouched. No new tool or public argument exists.
All ten tools and the healthcare comparison provider remain unchanged.

Route: simular_cambiar_umbral -> existing closed public mapping ->
execute(simular_escenario, accion=change_threshold) -> validated full raw result
-> existing claims/public projection -> additive threshold_transition_ledger.
One engine execution per public call. The new verifier checks the complete
raw partition against source-bound municipal/service coordinates and the
existing unrounded distance primitive. It does not alter engine arithmetic.

Contract: threshold_transition_ledger
- contract_version: "v1"; verified: true only after every check succeeds.
- baseline_threshold_km/scenario_threshold_km: actual numeric thresholds.
- baseline_threshold_m/scenario_threshold_m: corresponding metres.
- threshold_direction: increase | decrease | equal.
- counts: outside_to_inside, inside_to_outside, stays_inside, stays_outside,
  total; each an integer. Total is the number of valid evaluated raw rows.
- changed_rows: COMPLETE list, never top-N. Each row has municipality_code,
  municipality_name, distance_m (rounded display), exact bool fields
  baseline_within_threshold/scenario_within_threshold, transition and
  evidence_path into the full raw data. All changed rows occur exactly once.
- unchanged_counts: inside/outside; reconcile with counts.
- comparison_sentence, answer_table_markdown, semantic_limit_sentence:
  deterministic ready-to-copy text, not generated by a model.
- presentation_rule: use ledger authority, never infer omitted classifications.
- raw_result_sha256, evidence_versions, source_ids, reference_period bind the
  table to original evidence and the unchanged source assets.
- classification_rule and scope explicitly distinguish unrounded authority
  from presentation and municipal classification from population coverage.

Fail closed

thresholds, duplicate/omitted municipalities, non-bools, changed distances,
inconsistent classification, wrong identities/sources/periods/counts and
oversize JSON. Failures return error with no partial verified ledger or claims.

R27 rejects it, never replaces it with zero. Equal thresholds are supported.
